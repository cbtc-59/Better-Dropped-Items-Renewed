# Better Dropped Items Renewed

将 Draylar 的 Better Dropped Items（原版 1.19）的掉落物渲染逻辑，
在 Minecraft 1.21 Fabric 上以独立代码重新实现。

## 开发分工

- **豆包 (Doubao)** —— 代码生成
- **DeepSeek** —— debug
- **通义灵码 (Tongyi Lingma)** —— debug
- **cbtc-59** —— 逻辑微调、渲染偏移量调整及测试

## 协议说明

本模组基于 Draylar 的 [Better Dropped Items](https://github.com/Draylar/better-dropped-items) 的视觉效果逻辑重新实现，原项目使用 MIT 许可证发布。

本模组代码由 AI 生成，经 AI debug 和人工测试后发布。
